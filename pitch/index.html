How a round works

One round · 30–60 seconds of fight
Ephemeral rollup · delegated for the round's lifespan delegate_round commit + undelegate
01 Lobby Both sides deploy tokens into the round. Base layer
02 VRF draw The seed is drawn the moment the lobby closes. VRF
03 Fight Fighters collide and take value off each other. Rollup
04 Extract Bank what you have raided and walk, mid-fight. Rollup
05 Settle The result commits back and pays out. Base layer

The seed is drawn before anyone can see it, so the outcome is locked the instant entries close.

What we built on

Four pieces
01 Magic Router Players connect through it once. It gets each request to the right layer behind the scenes.
02 VRF We draw the fight seed on it right after the lobby closes, so the outcome is locked before anyone can see it.
03 Session keys Used for the extract action, so a player can bail mid-fight without a wallet pop-up.
04 delegate_round /
undelegate We open each round into the rollup, then commit and settle back to the main chain once the fight resolves.
